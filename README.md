# Finanças

Controle financeiro do casal em um único arquivo: **`financas.html`**.
Os dados (lançamentos, faturas, nomes) ficam **só no aparelho** de quem usa — nada é enviado para a internet.

## No computador

1. Baixe o `financas.html` para uma pasta do computador.
2. Abra com **Google Chrome** ou **Microsoft Edge**.
3. Clique em **💾 Salvar num arquivo do PC** e crie o arquivo de dados na mesma pasta.
   A partir daí, cada lançamento é gravado nesse arquivo automaticamente.
4. Nas próximas vezes, abra o `financas.html` e clique em **↻ Reconectar**.

Cópia de segurança: copie a pasta para um pendrive ou HD externo de vez em quando.

## Como aplicativo no celular

1. Abra o endereço do app no **Chrome** (Android) ou **Safari** (iPhone).
2. Menu (⋮) › **Instalar app** / **Adicionar à tela inicial**.
3. O ícone "Finanças" aparece junto com os outros apps e abre sem internet.

Os lançamentos ficam guardados só no celular. Para levar os dados de um aparelho para o outro:
**Ajustes › Exportar backup** num aparelho e **Ajustes › Juntar com outro aparelho** no outro
(soma o que falta, não apaga nada).

## O que tem

- **Entradas** por pessoa, com "recebido" ou "a receber" e o campo **"Quanto vai para a casa"**.
- **Gastos fixos** que se repetem todo mês, com valor ajustável por mês e financiamentos com parcelas.
- **Cartões** com fechamento e vencimento; compras parceladas caem sozinhas nas faturas certas.
- **Gastos do mês**, busca em todos os meses e detecção de lançamentos duplicados.
- **Resumo**: quanto falta para fechar o mês, saldo de cada um, contas a pagar e o que já está
  comprometido nos próximos meses.
- Os nomes das pessoas são definidos em **Ajustes › Nomes** e ficam só no aparelho.
